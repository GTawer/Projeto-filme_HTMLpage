Este repositório apresenta uma página web desenvolvida em **HTML** sobre o filme **Scott Pilgrim contra o Mundo**, como parte de uma atividade acadêmica do curso Técnico em Desenvolvimento de Sistemas do SENAI.

---

## 🎬 Descrição e objetivo do projeto

O projeto consiste na criação de uma página web simples e organizada sobre o filme **Scott Pilgrim contra o Mundo**, lançado em 2010 e dirigido por **Edgar Wright**.

A atividade tem como objetivo colocar em prática os conhecimentos aprendidos durante as aulas de **HTML**, utilizando corretamente elementos para estruturar títulos, imagens, textos e links.

A página apresenta informações básicas sobre o filme, sua sinopse, uma imagem relacionada à obra e links para acessar conteúdos complementares.

---

## 🎥 Filme escolhido

### Scott Pilgrim contra o Mundo

O filme acompanha **Scott Pilgrim**, um jovem baixista de uma banda de garagem que se apaixona por **Ramona Flowers**. Para poder ficar com ela, Scott precisa enfrentar os sete ex-namorados do mal de Ramona em batalhas inspiradas no universo dos videogames.

A obra combina elementos de **ação, comédia, romance e videogames**, criando uma identidade visual e narrativa bastante característica.
